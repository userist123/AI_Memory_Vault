# 08_RESEARCH

Research-only material for evidence-driven Memory Vault investigations.

This tree is intentionally separated from production mechanisms. Research artifacts may define hypotheses, frozen corpora, experiments, controls, provenance, and runtime evidence, but they must not silently promote knowledge into ACTIVE memory or alter production retrieval/consolidation behavior.

Book-to-Memory work follows:

SOURCE -> ENGINEERING HYPOTHESIS -> EXPERIMENT -> RUNTIME EVIDENCE -> DECISION

Raw book text is not a production retrieval source.
