## Research relevance
The publisher description explicitly frames the book around cognitive architecture and identifies declarative and procedural modules, with the declarative module described as providing an appropriate window into the past and the procedural module as developing productions for adaptive responses.

## Relevant research problems
- associative retrieval
- declarative/procedural interaction
- context-sensitive retrieval
- production/routing control
- learning and skill
- latency and cognitive resource constraints

## Engineering hypotheses — not conclusions
- H-A1: associative retrieval should be tested independently from lexical matching.
- H-A2: retrieval and control/routing should be measurable as separate stages even if they interact.
- H-A3: a useful memory mechanism must be evaluated under task/state constraints, not only isolated retrieval queries.

## Required experiment
Create indirect-cue tasks where the target memory is semantically or contextually related but shares few surface tokens with the query. Compare lexical baseline with a candidate-generation variant while keeping ranking and budget controls explicit.

## Limits
