## Engineering hypotheses — not conclusions
- H-NEW1: retrieval quality must be evaluated together with control/routing because the usefulness of a memory depends on what the agent is currently trying to do.
- H-NEW2: context should constrain candidate selection, not merely annotate retrieved records.
- H-NEW3: memory, learning and skill should be tested as interacting functions rather than isolated storage features.
- H-NEW4: token/latency budgets are architectural constraints and should be included in retrieval benchmarks.

## Required experiments
For the same memory corpus, compare retrieval under:
A. generic query,
B. task-specific query,
C. state/context-enriched query.
Measure recall, ranking quality, false retrieval, latency and tokens.
