## Engineering hypotheses — not conclusions
- H-SK1: Memory Vault may need a distinction between transient working state and durable stored knowledge.
- H-SK2: durable storage should not imply immediate retrieval eligibility.
- H-SK3: procedural knowledge may be more useful as an executable policy/procedure than as ordinary prose memory.
- H-SK4: repeated use and stabilization should be measured separately from mere storage age.

## Required experiments
Compare newly stored memories against stabilized memories under repeated tasks. Measure retrieval reliability, conflict rate, task success, token cost and persistence after intervening memories.

## Limits
The molecular/cellular mechanisms are not software mechanisms. The valid research output is a testable abstraction, not a biological simulation.
