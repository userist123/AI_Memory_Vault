## Engineering hypotheses — not conclusions
- H-MS1: retrieval may benefit from explicitly distinguishing memory role/type rather than treating all memories as one homogeneous retrieval pool.
- H-MS2: interference should be modeled as a retrieval/selection problem, not only as deletion or decay.
- H-MS3: context may determine which otherwise-valid memory is appropriate to expose.
- H-MS4: implicit/procedural knowledge may need a different access path from declarative recollection.

## Required experiment before implementation
Construct paired tasks where the same lexical cue maps to multiple memory types or conflicting memories. Measure retrieval precision, omission, conflict exposure, latency and token cost.

## Limits
This book describes biological/cognitive memory systems. It does not by itself justify a one-to-one software architecture.
