## 2. The 8 Mandatory Rules & Implementation Guarantees

### Rule 1: Boundary First
No query or retrieval traversal reaches `HybridRetriever` before traversing `RetrievalBoundaryAdapter.validate_and_normalize_filters()` and principal validation. Any invalid request (bad principal, broadening filter, empty filter set) raises an exception immediately, leaving `HybridRetriever.search_with_trace` uncalled (`SpyRetriever.call_count == 0`).

### Rule 2: Caller May Narrow, Never Broaden
The immutable trust ceiling is `ACTIVE + verified`.
- **Accepted**: `ACTIVE`, `verified`, more restrictive note types (`types=["procedure"]`), and non-privileged boundary subsets.
- **Strictly Rejected (fail-closed)**: `REVIEW`, `RAW`, `ARCHIVED`, `SUPERSEDED`, `RECONSOLIDATING`, `unverified`, `ai_generated`, `unknown`, any unrecognized string token, or empty filter lists (`[]`) used for bypass attempts. All raise `BoundaryViolationError` or `FilterValidationError`.

### Rule 3: Principal Propagation
The requesting principal identity is mandatory and immutable:
- No default principal (such as `AI_AGENT`) is assumed.
- Missing principal (`None` or `""`) is strictly fail-closed (`PrincipalValidationError`).
- Valid principals (`human`, `ai_agent`, `admin`, or enum instances) flow unaltered into the normalized request, the response object (`resp.principal`), and the audit trace (`trace["caller_principal"]`).

### Rule 4: Defense in Depth (Two-Layer Purge)
Even if a faulty or mock retriever returns notes outside the boundary (e.g. `RAW`, `REVIEW`, `ARCHIVED`, `SUPERSEDED`, or `unverified`), the facade's post-retrieval loop purges every non-compliant note before returning:
```python
sanitized_hits = [
    h for h in hits
    if h.note.lifecycle in ALLOWED_SECURE_LIFECYCLES
    and h.note.verification in ALLOWED_SECURE_VERIFICATION
]
```

### Rule 5: Determinism
Every execution on the same corpus and retriever state yields byte-for-byte identical result ordering, scores, and note IDs. Deterministic secondary sort is enforced:
$$\text{Sort Key} = (-\text{score}, \text{note.id})$$

### Rule 6: Pagination Transport
The facade transparently transports pagination contracts:
- Accepts `page_size` and `page_token` (offset-based or transparent token string).
- Calculates retrieval depth $k = \text{offset} + \text{page\_size}$.
- Slices results to the requested page window.
- Computes `next_page_token = f"offset:{offset + page_size}"` when additional hits exist.
- HMAC token signing remains the separate responsibility of `MemoryController`.

### Rule 7: Strict Separation of Authorization vs Boundary Validation
The facade **does not implement an authorization engine**:
- It does not evaluate `is_allowed(principal, Operation.SEARCH)`.
- It does not check user permissions, session tokens, or RBAC tables.
- Authorization is the strict responsibility of the upper calling layer (`MemoryController` and `Authorizer`).
- The facade is exclusively a structural and cryptographic trust boundary guardian for retrieval data.

### Rule 8: Absolute Storage Immutability
All retrieval operations are strictly read-only:
- Filesystem snapshots taken before and after retrieval verify 0 file creations, 0 file deletions, and 0 modifications (all `st_mtime_ns` and `st_size` unchanged).
- In-memory note objects are immutable.

## 3. Data Contracts

### 3.1 `FacadeRetrievalRequest`
```python
@dataclass(frozen=True)
class FacadeRetrievalRequest:
    query: str
    principal: Any                      # Mandatory: 'human', 'ai_agent', 'admin', or Principal enum
    request_id: Optional[str] = None    # Optional correlation ID
    lifecycles: Optional[Iterable[str]] = None
    verification: Optional[Iterable[str]] = None
    types: Optional[Iterable[str]] = None
    page_size: int = 10
    page_token: Optional[str] = None
    metadata: Optional[Dict[str, Any]] = None
```

### 3.2 `FacadeRetrievalResponse`
```python
@dataclass
class FacadeRetrievalResponse:
    results: List[FacadeNoteResult]     # Sanitized, verified hit items
    total_hits: int                     # Total matching hits across pages
    page_size: int                      # Page size applied
    page_token: Optional[str]           # Input page token
    next_page_token: Optional[str]      # Token for subsequent page (or None)
    query: str                          # Echoed query string
    principal: str                      # Normalized caller principal
    request_id: Optional[str]           # Request identifier
    effective_lifecycles: List[str]     # Enforced lifecycles (['ACTIVE'])
    effective_verification: List[str]   # Enforced verification (['verified'])
    effective_types: Optional[List[str]]# Types applied if narrowed
    trace: Dict[str, Any]               # Detailed execution & signal trace
    timestamp_utc: str                  # ISO-8601 UTC timestamp
```
