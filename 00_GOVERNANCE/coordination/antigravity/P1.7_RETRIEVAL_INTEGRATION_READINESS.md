## 4. Retrieval Integration Contract

The unified retrieval subsystem follows an unambiguous unidirectional pipeline:

```text
Caller (e.g. MemoryController)
  │  [Caller checks Operation.SEARCH authorization and provides authenticated Principal]
  ▼
ProductionRetrievalFacade
  │  - Validates request structure & fail-closed types (page_size, page_token)
  │  - Computes bounded retrieval depth: fetch_k = max(offset + page_size + 1, 10)
  │  - Enforces secondary defense-in-depth sanitization on emitted notes
  │  - Enforces strict deterministic sort: (-score, note.id)
  │  - Assembles FacadeRetrievalResponse with pagination tokens & audit trace
  ▼
RetrievalBoundaryAdapter
  │  - Validates principal identity against KNOWN_PRINCIPALS ("human", "ai_agent", "admin")
  │  - Enforces: "Caller may narrow, never broaden trust boundary"
  │  - Validates filter taxonomy; blocks RAW, REVIEW, ARCHIVED, SUPERSEDED, UNVERIFIED
  ▼
HybridRetriever
  │  - Lexical multi-signal (BM25 + rare technical entities)
  │  - Reciprocal Rank Fusion (RRF_K = 60)
  │  - In-memory read-only traversal over VaultIndex
  ▼
Corpus / Graph / Indexes
```

### 4.1 Request Contract (`FacadeRetrievalRequest`)
```python
@dataclass(frozen=True)
class FacadeRetrievalRequest:
    query: str                          # Search text query
    principal: Any                      # Mandatory: 'human', 'ai_agent', 'admin', or Principal enum
    request_id: Optional[str] = None    # Correlation / audit request ID
    lifecycles: Optional[Iterable[str]] = None      # Narrowing only (must be subset of {'ACTIVE'})
    verification: Optional[Iterable[str]] = None    # Narrowing only (must be subset of {'verified'})
    types: Optional[Iterable[str]] = None           # Optional narrowing by note type
    page_size: int = 10                             # Positive integer (non-boolean)
    page_token: Optional[str] = None                # Format: 'offset:<int>' or '<int>'
    metadata: Optional[Dict[str, Any]] = None       # Extensible caller metadata
```

### 4.2 Response Contract (`FacadeRetrievalResponse`)
```python
@dataclass
class FacadeRetrievalResponse:
    results: List[FacadeNoteResult]     # Sanitized hit items (id, title, score, lifecycle, verification, type, signals, preview)
    total_hits: int                     # Count of verified hits retrieved within current fetch window
    page_size: int                      # Page size applied
    page_token: Optional[str]           # Input page token supplied
    next_page_token: Optional[str]      # Token for subsequent page ('offset:<n>' or None if exhausted)
    query: str                          # Echoed query string
    principal: str                      # Normalized caller principal string
    request_id: Optional[str]           # Request identifier
    effective_lifecycles: List[str]     # Enforced lifecycles (['ACTIVE'])
    effective_verification: List[str]   # Enforced verification (['verified'])
    effective_types: Optional[List[str]]# Effective note types applied
    trace: Dict[str, Any]               # Detailed execution & signal trace
    timestamp_utc: str                  # ISO-8601 UTC timestamp
```

### 4.3 Contract Invariants & Semantics
1. **Authorization Assumptions**: The facade is **strictly non-authorizing**. Permission evaluation (`is_allowed(principal, Operation.SEARCH)`) is the sole responsibility of `MemoryController` / `Authorizer`. The facade validates principal presence and format, rejecting empty, missing, or unrecognized principals fail-closed.
2. **Lifecycle & Verification Ceiling**: The trust ceiling is permanently capped at `ACTIVE + verified`. Any attempt to pass `REVIEW`, `RAW`, `ARCHIVED`, `SUPERSEDED`, or `unverified` raises `BoundaryViolationError`.
3. **Filtering Semantics**: Callers may only narrow results within the trust boundary (e.g. `types=["knowledge"]`). Unknown tokens raise `FilterValidationError`.
4. **Pagination Semantics**: `page_token` must be a valid string formatted as `offset:<non-negative int>`. Malformed or non-numeric tokens raise `FilterValidationError`. Retrieval depth uses `fetch_k = max(offset + page_size + 1, 10)`, guaranteeing lookahead to accurately determine `next_page_token` existence across multi-page sequences.
5. **Deterministic Ordering**: Absolute tie-breaking is enforced: `key=lambda h: (-h.score, h.note.id)`.
6. **Failure Behavior**: Fail-closed on all structural and boundary violations (`PrincipalValidationError`, `FilterValidationError`, `BoundaryViolationError`).
7. **Storage Immutability**: All retrieval operations execute 0 disk writes and 0 note mutations.
