## 2. Audit of Retrieval Facade & Boundary

The retrieval facade (`cognitive_core/retrieval_facade.py`), boundary adapter (`cognitive_core/retrieval_boundary.py`), and test suites were audited against 13 operational criteria:

1. **Principal Propagation**: Principal identity (`human`, `ai_agent`, `admin`) is mandatory and flows unmodified into the response and audit trace. Missing, empty, or unverified principals fail closed with `PrincipalValidationError`.
2. **ACTIVE + Verified Ceiling**: Strictly capped at `ACTIVE` lifecycle and `verified` verification. Any caller attempts to pass `REVIEW`, `RAW`, `ARCHIVED`, `SUPERSEDED`, or `unverified` raise `BoundaryViolationError`.
3. **Lifecycle Filtering**: Callers may narrow within `{ACTIVE}`; broadening is strictly prevented.
4. **Narrowing vs Broadening**: Caller narrowing by note type (e.g. `types=["knowledge"]`) or lifecycle is honored. Expanding beyond the boundary is blocked fail-closed.
5. **Deterministic Ordering**: Absolute tie-breaking is enforced: `key=lambda h: (-h.score, h.note.id)`. Identical queries yield byte-for-byte identical result rankings and scores across invocations.
6. **Pagination Sequence & Depth**: Identified and resolved a fetch cutoff gap. Retrieval depth is calculated as `fetch_k = max(offset + page_size + 1, 10)`, guaranteeing lookahead to accurately determine `next_page_token` presence across arbitrary page counts without truncating results.
7. **Invalid Pagination Token Handling**: Non-string tokens, non-numeric offsets (`offset:abc`), negative offsets (`offset:-5`), and malformed formats raise `FilterValidationError`, preventing infinite pagination loops.
8. **Boolean `page_size` Guard**: Explicitly rejects boolean values (`page_size=True` or `page_size=False`) with `FilterValidationError`.
9. **Read-Only Behavior**: Filesystem stat snapshots before and after queries confirm 0 file creations, deletions, or modifications.
10. **Trace & Evidence Completeness**: The response trace records `caller_principal`, `request_id`, `boundary_filters`, candidate rankings across arms, and pagination metrics (`page_size`, `offset`, `total_hits`, `returned_count`, `has_next_page`).
11. **Empty Result Behavior**: Queries returning 0 matches produce `results=[]`, `total_hits=0`, `next_page_token=None` gracefully without crashing.
12. **Invalid Filter Handling**: Empty filter sequences, unknown lifecycle tokens, and non-string queries fail closed with specific exception types.
13. **Retriever Contract Isolation**: Underlying retriever is never called if structural or boundary validation fails.

## 7. Integration Readiness Contract

The target integration pipeline for subsequent consumption:

```text
Caller (e.g. MemoryController)
  │  [Checks Operation.SEARCH permission & supplies authenticated Principal]
  ▼
ProductionRetrievalFacade
  │  - Input: FacadeRetrievalRequest
  │  - Validates page_size (int > 0, non-bool) & page_token ('offset:<int>')
  │  - Depth: fetch_k = max(offset + page_size + 1, 10)
  │  - Secondary defense-in-depth sanitization: ACTIVE + verified
  │  - Deterministic sort: (-score, note.id)
  │  - Output: FacadeRetrievalResponse with pagination tokens & audit trace
  ▼
RetrievalBoundaryAdapter
  │  - Normalizes principal ("human", "ai_agent", "admin")
  │  - Enforces: "Caller may narrow, never broaden"
  │  - Rejects RAW, REVIEW, ARCHIVED, SUPERSEDED, unverified
  ▼
HybridRetriever
  │  - Multi-signal BM25 + rare technical entities
  │  - RRF fusion (k=60)
  │  - Pure in-memory read-only traversal over VaultIndex
  ▼
Indexes / Graph / Corpus
```

### 7.1 Detailed Invariants:
- **Input**: `FacadeRetrievalRequest(query, principal, request_id, lifecycles, verification, types, page_size, page_token, metadata)`.
- **Output**: `FacadeRetrievalResponse(results, total_hits, page_size, page_token, next_page_token, query, principal, request_id, effective_lifecycles, effective_verification, effective_types, trace, timestamp_utc)`.
- **Ceiling**: Capped strictly at `ACTIVE + verified`.
- **Pagination**: Transparent offset-based pagination (`next_page_token = "offset:<n>"` or `None`).
- **Errors**: Fail closed with `PrincipalValidationError`, `FilterValidationError`, or `BoundaryViolationError`.
- **Storage**: 100% read-only guarantee.
