# Matricea de Skill-uri a Consiliului de Agenți

Pentru a facilita execuția autonomă la scară largă, fiecărui agent specializat i-au fost alocate skill-urile și documentele de referință (KNOWLEDGE) specifice domeniului său. Agenții vor apela automat aceste skill-uri atunci când sunt invocați.

## 1. WPF Engineer (`wpf_engineer`)
*Domeniu:* C# WPF, .NET 10, MVVM, Desktop Enterprise.
**Skill-uri Antigravity alocate:**
- `ui-tokens`: Impune utilizarea exclusivă a tokeni-lor din `ObsidianTactical.xaml` (fără hex hardcodat).
- `security-invariants`: Garantează că orice cod respectă cerințele air-gapped și P0-P18.
**Memorie Canonică de citit la rulare:**
- `01_KNOWLEDGE/CSharp_WPF_Enterprise_Desktop.md`
- `01_KNOWLEDGE/Registru_Transferuri_Development_Standards.md`

## 2. SecOps & Forensic Auditor (`secops_auditor`)
*Domeniu:* Securitate, PowerShell, Conformitate HG 585, NIST.
**Skill-uri Antigravity alocate:**
- `dfir-operations`: Proceduri multi-pas pentru analiză criminalistică (Forensics) și executarea playbook-urilor de izolare (LogAnalyzer DFIR).
- `vault-security-audit`: Runbook pentru testarea limitelor de încredere și validarea invariantelor P0-P15.
- `audit-verify-explain-grade-5`: Auditarea muncii, verificarea dovezilor și explicarea rezultatelor în limbaj clar (pentru rapoarte finale).
- `security-invariants`: Aplică HG 585/2002, EUCI, NATO AC/35.
**Memorie Canonică de citit la rulare:**
- `03_PROCEDURES/PowerShell_SecOps_Forensic_Standard.md`

## 3. UI/UX Designer (`ui_ux_designer`)
*Domeniu:* Interfețe Dashboard, Identitate Vizuală, Motion Design.
**Skill-uri Antigravity alocate:**
- `design-first-ui-prompting`: Prompting orientat pe design, specificații și layout-uri consistente.
- `aura-asset-images` & `unsplash-asset-images`: Integrarea resurselor vizuale (imagini/mockup-uri de înaltă calitate) cu raport corect de aspect.
- `build-daily-inspiration-sites`: Crearea de landing page-uri pornind de la referințe de inspirație UI (Framer/Dribbble).
- `video-to-superprompt`: Extragerea mecanicii de animație UI din materiale video.
**Memorie Canonică de citit la rulare:**
- `01_KNOWLEDGE/Dashboard_Admin_UI_Architecture.md`
- `01_KNOWLEDGE/Brand_Identity_Guidelines.md`

## 4. Quant Developer (`quant_developer`)
*Domeniu:* Trading algoritmic, arhitecturi de risc (Python).
**Skill-uri Antigravity alocate:**
- `performance-profiling`: Diagnosticarea latențelor, utilizării CPU/GPU și memory leaks în buclele de backtesting.
- `iterate-until-verified`: Aplicarea execuției și verificării recurente (fără a opri task-ul) pentru eliminarea look-ahead bias-ului.
**Memorie Canonică de citit la rulare:**
- `01_KNOWLEDGE/Python_Algorithmic_Trading_Architecture.md`

## 5. Local AI Integration Engineer (`local_ai_engineer`)
*Domeniu:* Modele LLM locale (Ollama), Vault Cognitiv.
**Skill-uri Antigravity alocate:**
- `vault-operations`: Runbook și proceduri multi-pas pentru interacțiunea cu ecosistemul AI Memory Vault.
- `iterate-until-verified`: Verificare automată și impunere harsh critic pentru output-uri structurate de tip JSON.
**Memorie Canonică de citit la rulare:**
- `01_KNOWLEDGE/Local_AI_Integration_Architecture.md`
- `01_KNOWLEDGE/Registru_Multi_Agent_Contracts.md`

## 6. Frontend SaaS Engineer (`frontend_saas_engineer`)
*Domeniu:* Next.js, Framer Motion, Performanță Web.
**Skill-uri Antigravity alocate:**
- `optimize-web-animations`: Profilare și auditare a animațiilor CSS/Framer Motion.
- `stitched-full-page-capture`: Audit vizual de înaltă fidelitate pe pagini lungi.
- `publish-project-to-github`: Pregătirea pachetelor, README și validarea deploy-ului web.
