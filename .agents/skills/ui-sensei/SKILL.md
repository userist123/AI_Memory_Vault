# UI Sensei — Design Philosophy & Visual Hierarchy

## 1. Principiile UI Sensei
- **Claritate de Durată (Lasting Clarity)**: Interfața trebuie să fie lizibilă și intuitivă chiar și fără onboarding.
- **Eliminarea Zgomotului Vizual (De-cluttering)**: Niciun element decorativ fără scop funcțional. Subliniază conținutul, nu rama.
- **Micro-Distanțări Ritmice**: Utilizarea sistemului modular de 4px / 8px / 16px / 24px / 32px / 48px.
- **Ierarhie Tipografică cu 3 Niveluri**: Titlu principal (Primary Focal), Subtitlu/Secțiune (Secondary Guide), Text Corp/Utilitar (Data Stream).

## 2. Ghid de Execuție UI
- Fundaluri întunecate mat / Obsidian cu straturi elevation discrete (`BgDeep` -> `BgBase` -> `BgCard` -> `BgElevated`).
- Stări de interacțiune clare: Default, Hover (+10% luminozitate sau border subtle), Focus (Inel vizibil FocusViolet/FocusCyan), Pressed, Disabled.
- Feedback vizual instantaneu la acțiuni (< 100ms).
