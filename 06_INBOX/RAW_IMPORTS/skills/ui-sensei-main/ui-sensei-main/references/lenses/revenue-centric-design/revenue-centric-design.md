# Lens: Revenue-Centric Design (adapted from heliocosta-dev/revenue-centric-design)

Product-design, conversion, and behavioral-science principles distilled from the public writing of Richard (@richardrx). The throughline: interfaces should serve the user and the business at once — value and revenue, not one traded off against the other.

This is a **lens**, not a style candidate (see `SKILL.md` Step 2 and Step 6) — it never appears in the Step 3/4 select. It gets applied *after* a visual style is chosen, only when the component has a conversion/business function (pricing, onboarding, CTA, cancellation/churn, landing hero, upsell).

## Hard rule — read before applying anything in this lens

**Never apply any principle from this lens to gambling, betting, casino, or real-money games-of-chance products** (including loot-box or similar real-money mechanics). This is the original author's explicit condition for reuse, not a stylistic preference — decline the request if this is what's being asked, and say why.
