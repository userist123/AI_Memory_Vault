**Coverage note:** thinner grounding than the core themes at curation time — expand against the actual source before relying on this heavily.

## Principle: verify the dominance relationship before shipping a comparative design

- **Apply when:** shipping any design that relies on a comparison effect (a decoy pricing tier, a "most popular" badge, a before/after framing).
- **The move:** these effects only work in the intended direction if the comparison is actually structured correctly — a decoy that's accidentally dominated by the *wrong* option shifts behavior the wrong way. Before shipping, explicitly check which option the comparison structure favors, rather than assuming the intended effect will hold.
- **Evidence:** general caution echoed across decoy-effect literature broadly (not RCD-specific) — a poorly-constructed decoy can measurably reduce revenue instead of increasing it, so this is a “test, don't assume” instruction rather than a one-time setup.
- **Visual:** an A/B test on a new pricing-tier arrangement before rolling it out broadly, rather than shipping the untested version.

## Gotcha this theme flags explicitly

Real scarcity ("3 spots left this week," verified against actual capacity) is a legitimate use of urgency; fabricated scarcity is not — and the difference is measurable in how it holds up under scrutiny or repetition, not just in intent. Track whether urgency claims remain true over time before reusing them as a permanent pattern.
