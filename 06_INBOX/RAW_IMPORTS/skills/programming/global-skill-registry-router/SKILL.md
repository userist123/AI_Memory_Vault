# Global Skill Registry Router (50,000+ Agent Skills & MCP Tools)

Acest skill activează capacitatea agenților din Vault de a interoga și descărca dinamic orice skill, workflow sau unealtă MCP din registrele globale.

## 1. Surse de Registre de Skill-uri Indexate (50.000+)

1. **VoltAgent Awesome Agent Skills (1.000+ Skills)**: `https://github.com/VoltAgent/awesome-agent-skills`
2. **Composio Tool & Action Registry (10.000+ Tool Actions)**: `https://github.com/ComposioHQ/awesome-claude-skills`
3. **Sickn33 Agentic Awesome Skills (AAS Core Control Plane)**: `https://github.com/sickn33/agentic-awesome-skills`
4. **GitHub Copilot Marketplace & Plugins (1.000+ Custom Instructions & Agents)**: `https://awesome-copilot.github.com/llms.txt`
5. **Bergside TypeUI Registry (67+ Visual Design Skills)**: `npx typeui.sh list`
6. **Model Context Protocol (MCP) Ecosystem (35.000+ Integrări APIs/Tools)**: `mcp_config.json` & MCP Registry.

## 2. Mecanism de Descoperire Progresivă (Progressive Disclosure)

Pentru a nu depăși fereastra de context LLM:
- **Local Active Vault**: 198 de SKILL-uri fundamentale stocate direct în `.agents/skills/`.
- **Global Dynamic Index**: Peste 50.000+ de skill-uri accesibile prin interogări pe indexul `Global_50K_Skill_Registries_Index.md` și descărcare la cerere în timpul execuției sarcinilor.
