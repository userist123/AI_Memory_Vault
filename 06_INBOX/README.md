# 06_INBOX

Zona temporara pentru informatii noi.

## Workflow

```text
RAW
 -> CLASSIFY
 -> EXTRACT
 -> DEDUPLICATE
 -> VALIDATE
 -> LINK
 -> MOVE
```

## Subfoldere

- `RAW_IMPORTS` — exporturi originale
- `PROCESSING` — continut aflat in procesare
- `QUARANTINE` — continut problematic, ambiguu sau suspect

## Important

RAG-ul nu trebuie sa trateze RAW_IMPORTS ca memorie verificata.
