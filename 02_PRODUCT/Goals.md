# Goals

## North Star

Construirea unui sistem AI cu memorie persistenta, retrieval controlat, knowledge graph, verificare si continuitate intre modele si sesiuni.

## Phase 1 — Foundation

- [ ] Vault unificat
- [ ] Taxonomie stabila
- [ ] Templates
- [ ] Import pipeline
- [ ] Confidence model
- [ ] Reguli de validare

## Phase 2 — Historical Memory

- [ ] Import ChatGPT
- [ ] Import Claude
- [ ] Import Perplexity
- [ ] Import Gemini / alte surse daca exista
- [ ] Deduplicare
- [ ] Clasificare
- [ ] Extrage decizii, erori si lectii

## Phase 3 — Retrieval

- [ ] Full-text search
- [ ] Semantic search
- [ ] Hybrid retrieval
- [ ] Metadata filtering
- [ ] Graph retrieval
- [ ] Re-ranking
- [ ] Context budget

## Phase 4 — Cognitive Layer

- [ ] Planner
- [ ] Reasoner
- [ ] Validator
- [ ] Watchdog
- [ ] Goal tracking
- [ ] Learning loop

## Phase 5 — Multi-model Continuity

- [ ] Shared memory
- [ ] Source-aware retrieval
- [ ] Model-specific adapters
- [ ] Conflict resolution
- [ ] Memory provenance

## Success Criteria

Sistemul trebuie sa poata raspunde la:

> "Ce stim deja despre acest subiect?"

si sa poata separa:

- ce este verificat;
- ce este experienta;
- ce este decizie;
- ce este ipoteza;
- ce este depasit.
