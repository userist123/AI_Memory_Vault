# 05_RESOURCES

Surse externe si materiale de referinta.

## Exemple

- documentatie oficiala;
- manuale;
- standarde;
- articole;
- exporturi;
- fisiere tehnice.

## Rule

Resource != knowledge.

O sursa este materialul. Knowledge este informatia extrasa si validata din sursa.
