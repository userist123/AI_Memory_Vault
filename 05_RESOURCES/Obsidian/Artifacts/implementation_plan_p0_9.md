# P0-9 Audit Implementation Plan

## Goal Description
Implement and verify the audit logging layer (P0-9) to ensure all successful and failed interactions with the AI Memory Vault are securely logged with strict schema requirements.

## User Review Required
- Is the current local file persistence for `audit_log.jsonl` sufficient for P0-9, or should the logger be adapted to inject into the `99_SYSTEM` directory? Currently, it outputs to `$ANTIGRAVITY_ARTIFACT_DIR/audit_log.jsonl`.
- I will wrap controller operations to ensure `Exception`s generate a `success=False` audit entry before propagating to the caller. Does this approach align with your expectations for failed operation logging?

## Proposed Changes

### `memory_controller/controller.py`
- Modify the core controller operations (`read`, `search`, `propose`, `update`, `review`, `promote`, `archive`) to capture and log failed operations.
- This will be achieved by wrapping the method logic in a `try/except Exception` block. Upon catching an exception, it will call `audit_event(..., success=False, details={'error': str(e)})` before re-raising the exception.
- Ensure the `target_id` is consistently passed to the audit logger (e.g., using `query` for search operations, and `note_id` for others).

### `memory_controller/tests/test_audit.py`
- **[NEW]** file: Create a dedicated test suite to verify the audit logger strictly complies with P0-9 requirements.
- **Tests to implement:**
  1. `test_audit_read`: Verify `read` operations produce a successful audit log.
  2. `test_audit_search`: Verify `search` operations produce a successful audit log.
  3. `test_audit_mutation`: Verify `propose` and `archive` operations produce a successful audit log.
  4. `test_audit_failed_operation`: Intentionally trigger a `PermissionError` and `ValueError`, and verify the audit log captures the `outcome="error"` and the error details.
  5. `test_audit_required_fields`: Assert that all logged JSON lines contain the mandatory schema fields: `timestamp`, `actor`, `operation`, `target_id`, and `outcome`.
