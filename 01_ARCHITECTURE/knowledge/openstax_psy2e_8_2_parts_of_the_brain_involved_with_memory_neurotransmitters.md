## 2. Concepte Extrase și Validate Verbatim

### 1. Neurotransmitters in Memory
Neurotransmitters such as epinephrine, dopamine, serotonin, glutamate, and acetylcholine are essential for the process of memory. Communication between neurons via these chemicals is critical for developing new memories and facilitating memory consolidation through repeated activity.

> "Although we don’t yet know which role each neurotransmitter plays in memory, we do know that communication among neurons via neurotransmitters is critical for developing new memories."

### 2. Arousal Theory
Arousal theory posits that strong emotional experiences trigger the release of neurotransmitters and hormones that strengthen memory formation. Consequently, emotional events are typically remembered more effectively than non-emotional events.

> "It is also believed that strong emotions trigger the formation of strong memories, and weaker emotional experiences form weaker memories; this is called arousal theory (Christianson, 1992)."

### 3. Flashbulb Memory
A flashbulb memory is an exceptionally clear and detailed recollection of an important or unusual event. These memories are often associated with strong emotions and can pertain to both global historic events and personal life experiences.

> "A flashbulb memory is an exceptionally clear recollection of an important event"

### 4. Memory Reconstruction
Memory is not a static recording but a process of reconstruction where various components like time, visuals, and smells are stored in different brain regions. During retrieval, these components are reassembled, which introduces the potential for errors.

> "When something is remembered, these components have to be put back together for the complete memory, which is known as memory reconstruction."

### 5. False Memory
False memory refers to the phenomenon where an individual remembers an event or information that did not actually occur. Research indicates that human memory is frail and susceptible to inaccuracies over time.

> "False memory is remembering something that did not happen."
