## 2. Concepte Extrase și Validate Verbatim

### 1. Memory
Memory is defined as an information processing system that functions similarly to a computer. It encompasses the set of processes utilized to encode, store, and retrieve information across various timeframes.

> "Memory is the set of processes used to encode, store, and retrieve information over different periods of time"

### 2. Encoding
Encoding is the initial phase of the memory process. It involves the input of information into the memory system.

> "Encoding involves the input of information into the memory system."

### 3. Storage
Storage is the second function of memory. It refers to the retention of information that has been previously encoded.

> "Storage is the retention of the encoded information."

### 4. Retrieval
Retrieval is the third function of memory. It is the process of accessing stored information and bringing it back into conscious awareness.

> "Retrieval, or getting the information out of memory and back into awareness, is the third function."
