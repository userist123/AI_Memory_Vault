## 2. Concepte Extrase și Dovezi Textuale Verificate

### 1. Atkinson-Shiffrin Model Stages
According to Richard Atkinson and Richard Shiffrin's model, information must pass through three distinct stages to reach long-term storage: sensory memory, short-term memory, and long-term memory.

> **Citat Verificat Sursă**:
> "In order for a memory to go into storage (i.e., long-term memory), it has to pass through three distinct stages: Sensory Memory , Short-Term Memory , and finally Long-Term Memory . These stages were first proposed by Richard Atkinson and Richard Shiffrin (1968)."

- **Termeni cheie**: Atkinson and Shiffrin, Sensory Memory, Short-Term Memory, Long-Term Memory

### 2. Baddeley and Hitch Working Memory Model
Baddeley and Hitch's model posits that short-term working memory stores information across three systems—a visuospatial sketchpad, an episodic buffer, and a phonological loop—under the supervision of a central executive.

> **Citat Verificat Sursă**:
> "There are memories in visual-spatial form, as well as memories of spoken or written material, and they are stored in three short-term systems: a visuospatial sketchpad, an episodic buffer (Baddeley, 2000), and a phonological loop. According to Baddeley and Hitch, a central executive part of memory supervises or controls the flow of information to and from the three short-term systems"

- **Termeni cheie**: working memory, visuospatial sketchpad, phonological loop, central executive, episodic buffer

### 3. Sensory Memory
Sensory memory functions as the initial storage of brief sensory events (such as sights, sounds, and tastes) lasting up to a couple of seconds before unattended details are discarded.

> **Citat Verificat Sursă**:
> "In the Atkinson-Shiffrin model, stimuli from the environment are processed first in sensory memory : storage of brief sensory events, such as sights, sounds, and tastes. It is very brief storage—up to a couple of seconds."

- **Termeni cheie**: sensory memory, storage, sensory events

### 4. Short-Term Memory Duration and Role
Short-term memory is a temporary storage component of working memory that retains incoming sensory information for roughly 15 to 30 seconds before it is either consolidated into long-term memory or discarded.

> **Citat Verificat Sursă**:
> "Short-term memory (STM) is a temporary storage system that processes incoming sensory memory. The terms short-term and working memory are sometimes used interchangeably, but they are not exactly the same. Short-term memory is more accurately described as a component of working memory."

- **Termeni cheie**: short-term memory, working memory, temporary storage

### 5. Rehearsal Mechanisms
Transferring information from short-term to long-term memory can occur via active rehearsal, which involves repetitive practice, or elaborative rehearsal, which links new information to existing knowledge.

> **Citat Verificat Sursă**:
> "Active rehearsal is a way of attending to information to move it from short-term to long-term memory. During active rehearsal, you repeat (practice) the information to be remembered."

- **Termeni cheie**: active rehearsal, elaborative rehearsal, long-term memory

### 6. Capacity of Short-Term and Working Memory
George Miller established that short-term memory capacity is roughly 7 plus or minus 2 items, whereas contemporary research indicates working memory capacity is approximately 4 plus or minus 1.

> **Citat Verificat Sursă**:
> "In 1956, George Miller reviewed most of the research on the capacity of short-term memory and found that people can retain between 5 and 9 items, so he reported the capacity of short-term memory was the "magic number" 7 plus or minus 2. However, more contemporary research has found working memory capacity is 4 plus or minus 1 (Cowan, 2010)."

- **Termeni cheie**: George Miller, capacity, short-term memory, working memory
