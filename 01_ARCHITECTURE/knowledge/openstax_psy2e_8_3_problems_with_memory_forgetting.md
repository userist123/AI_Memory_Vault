## 2. Concepte Extrase și Validate Verbatim

### 1. Forgetting
Forgetting is defined as the loss of information from long-term memory. It is a common human experience that can be attributed to various psychological mechanisms, including encoding failures, memory errors, and interference.

> "Forgetting refers to loss of information from long-term memory."

### 2. Encoding Failure
Encoding failure occurs when information is never successfully stored in long-term memory because it was not processed with sufficient attention or effort. Without this initial storage, the information cannot be retrieved later.

> "Sometimes memory loss happens before the actual memory process begins, which is encoding failure. We can’t remember something if we never stored it in our memory in the first place."

### 3. Storage Decay
Storage decay is the process where unused information fades from memory over time. This phenomenon was famously quantified by Hermann Ebbinghaus, who demonstrated that memory retention drops significantly shortly after learning and then levels off.

> "What is going on here is storage decay: unused information tends to fade with the passage of time."

### 4. Absentmindedness
Absentmindedness refers to memory errors caused by lapses in attention or focus. It occurs when an individual is distracted, leading to a failure to encode or retrieve information effectively.

> "absentmindedness , which describes lapses in memory caused by breaks in attention or our focus being somewhere else."

### 5. Misattribution
Misattribution is a memory distortion where an individual confuses the source of a memory. This can lead to the creation of false memories, such as attributing a dream to a waking experience or confusing the identity of a person seen in different contexts.

> "Misattribution happens when you confuse the source of your information."

### 6. Suggestibility
Suggestibility is a memory distortion where false memories are created due to external influence. Unlike misattribution, which is self-generated, suggestibility often results from leading questions asked by others, such as police or therapists.

> "With suggestibility, it comes from someone else, such as a therapist or police interviewer asking leading questions of a witness during an interview."

### 7. Bias
Bias refers to the distortion of memories based on an individual's current feelings, beliefs, or worldviews. Types of bias include stereotypical, egocentric, and hindsight bias, all of which reconstruct past events to align with present perspectives.

> "Schacter (2001) says that your feelings and view of the world can actually distort your memory of past events."

### 8. Persistence
Persistence is the involuntary recall of unwanted, often traumatic, memories. It is considered a failure of the memory system because these intrusive thoughts interfere with an individual's ability to concentrate on other tasks.

> "It’s actually a failure of our memory system because we involuntarily recall unwanted memories, particularly unpleasant ones"

### 9. Interference
Interference occurs when stored information becomes inaccessible due to the presence of other information. Proactive interference happens when old information hinders new learning, while retroactive interference happens when new information hinders the recall of older information.

> "Sometimes information is stored in our memory, but for some reason it is inaccessible. This is known as interference"
