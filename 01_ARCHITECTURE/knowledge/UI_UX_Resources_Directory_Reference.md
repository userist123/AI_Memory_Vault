This note summarizes the full category list and highlights entries most relevant to this project's prioritized stack (React 18+, Tailwind CSS 3+, Framer Motion, WCAG 2.2 accessibility). Full link list lives at the source repository, not duplicated here in full.

## Highlights Relevant to This Project's Stack

### React UI libraries (directly applicable)
- **Material UI** -- React components based on Material Design.
- **Chakra UI** -- accessible React component library, explicitly listed as a priority library in this project's instructions.
- **Framer Motion** -- production-ready React animation library, already a priority per this project's instructions.
- **Ant Design** -- enterprise-grade React UI library.
- **Theme UI** -- constraint-based theming for React, relevant to design-token/theming work.
- **React Spring** -- spring-physics animation library.
- **PrimeReact** -- accessible, flexible React UI components.

### CSS Frameworks (directly applicable)
- **Tailwind CSS** -- already the project's prioritized utility-first framework.

### Icons (Heroicons/Lucide equivalent guidance already in project instructions)
- **Heroicons** -- from the creators of Tailwind CSS, explicitly aligned with project instructions ("Iconuri: SVG inline sau Heroicons, Lucide").
- **Tabler Icons**, **Feather Icons**, **Simple Icons** -- open-source SVG icon sets, alternates to Lucide.

### CSS Animations / JS Animation Libraries
- **Animate.css**, **Anime.js**, **GreenSock (GSAP)** -- for microinteractions per project's UI/UX priorities.
- **tsParticles / particles.js** -- particle effects, potential hero-section visual enhancement.

### Design Systems & Style Guides (reference for design tokens)
- **Material Design** (Google), **Ant Design**, **Primer** (GitHub's design system), **Carbon** (IBM), **Polaris** (Shopify), **Spectrum** (Adobe), **Laws of UX** -- useful reference examples of mature, documented design-token systems for this project's own design-system work.

### Colors
- **Coolors**, **Adobe Color**, **Khroma** (AI-assisted palette generation), **whocanuse** / **Colorable** (contrast-accessibility testing tools -- directly relevant to this project's WCAG 2.2 AA contrast requirement of >4.5:1).

### Online Design Tools
- **Figma** -- industry-standard design tool; relevant if integrating with a design-to-code workflow (see also `penpot-mcp` reference note for an MCP-based design-tool bridge pattern).

## Notes / Caveats

- Repository last updated October 2023; some linked third-party resources may be outdated, discontinued, or have changed licensing terms. Verify each resource's current license and availability before adopting it in production code.
- This is a link directory, not a code library -- no direct dependency or integration risk, purely a reference/discovery resource.
