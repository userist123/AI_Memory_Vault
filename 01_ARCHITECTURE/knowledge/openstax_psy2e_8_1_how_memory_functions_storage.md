## 2. Concepte Extrase și Validate Verbatim

### 1. Atkinson-Shiffrin Model
Proposed in 1968, this model posits that human memory functions similarly to a computer, processing information through three distinct stages: sensory memory, short-term memory, and long-term memory. It serves as a foundational framework for understanding how information is stored.

> "Their model of human memory ( Figure 8.4 ), called Atkinson and Shiffrin's model, is based on the belief that we process memories in the same way that a computer processes information."

### 2. Sensory Memory
Sensory memory is the initial stage of storage that captures brief sensory events such as sights, sounds, and tastes. This information is extremely transient, lasting only up to a couple of seconds before being discarded or moved to short-term memory.

> "In the Atkinson-Shiffrin model, stimuli from the environment are processed first in sensory memory : storage of brief sensory events, such as sights, sounds, and tastes."

### 3. Short-Term Memory
Short-term memory is a temporary storage system that processes incoming information from sensory memory. It typically lasts between 15 and 30 seconds and acts as a component of working memory.

> "Short-term memory (STM) is a temporary storage system that processes incoming sensory memory."

### 4. Active Rehearsal
Active rehearsal is a cognitive strategy used to move information from short-term memory into long-term memory. It involves the repetitive practice of information to facilitate its retention.

> "During active rehearsal, you repeat (practice) the information to be remembered."

### 5. Proactive Interference
Proactive interference occurs when previously learned information hinders the ability to acquire or recall new information. It is a significant factor affecting short-term memory retention.

> "During proactive interference, previously learned information interferes with the ability to learn new information."

### 6. Semantic Network
Memories are organized into semantic or associative networks consisting of concepts, which are categories of linguistic information, ideas, or experiences. Related concepts are linked, and the strength of these links depends on the frequency of their association.

> "It is generally accepted that memories are organized in semantic (or associative) networks (Collins & Loftus, 1975)."

### 7. Spreading Activation
Spreading activation is the process where activating one part of a semantic network partially activates linked concepts. This makes associated information easier to access and recall.

> "If one part of a network is activated, it is easier to access the associated concepts because they are already partially activated."

### 8. Explicit Memory
Explicit memory, also known as declarative memory, consists of information that we consciously attempt to remember and report. It is further categorized into episodic and semantic memory.

> "Explicit memories are those we consciously try to remember, recall, and report."

### 9. Implicit Memory
Implicit memory refers to long-term memories that are not part of our conscious awareness but are demonstrated through the performance of tasks. These memories influence behavior and cognitive processes without requiring conscious recall.

> "Implicit memories are long-term memories that are not part of our consciousness."

### 10. Hyperthymesia
Hyperthymesia is a rare condition characterized by a highly superior autobiographical memory. Individuals with this condition can recall vast amounts of specific life events with extreme accuracy.

> "Marilu Henner’s super autobiographical memory is known as hyperthymesia."
