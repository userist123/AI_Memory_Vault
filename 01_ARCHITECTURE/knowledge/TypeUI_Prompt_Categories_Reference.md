# TypeUI Prompt Categories Reference

## Context

TypeUI (typeui.sh) is an external library of 449 curated UI design prompts, organized by category, intended for use with AI coding agents (Codex, Claude, Cursor) via TypeUI's own connector integration. The full prompt text for each category is gated behind that connector and is NOT publicly visible on the category pages; only category-level descriptions are public.

This note captures the publicly available category descriptions for three categories of interest. It does NOT contain the actual prompt text, since that requires connecting TypeUI directly to a coding agent.

## Hero Sections

Create high-converting hero sections that instantly capture attention, communicate your value proposition, and guide visitors toward action with clear messaging, visuals, and CTAs.

Source: https://www.typeui.sh/prompts/hero

## Pricing Sections

Create high-converting pricing sections that clearly present your plans, highlight the best-value option, address buying concerns, and guide visitors toward confident purchase decisions with transparent pricing, feature comparisons, and compelling CTAs.

Source: https://www.typeui.sh/prompts/pricing

## Sidebars

Create application sidebars that organize product navigation, workspace sections, nested links, and account controls in a clear vertical structure, helping users move between tools efficiently while supporting hierarchy, active states, collapsible groups, responsive behavior, and quick access to key actions.

Source: https://www.typeui.sh/prompts/sidebars

## Follow-up Options

To obtain the actual prompt text (not just descriptions), one of the following is required:
1. Connect TypeUI directly to a coding agent (Codex, Claude, or Cursor) via TypeUI's own integration.
2. Manually copy prompt text from the TypeUI dashboard after connecting an account.
3. Export/paste prompt text directly for structured ingestion into this Vault.

This note should be superseded or updated once actual prompt content is obtained and verified.
