# Tag Taxonomy

Tags support retrieval and cross-cutting classification; they do not replace `type`, `lifecycle`, or `category`.

## Controlled prefixes

| Prefix | Use |
|---|---|
| `domain/` | subject area, e.g. `domain/ai` |
| `project/` | project affiliation, e.g. `project/ai-memory-system` |
| `topic/` | reusable topic, e.g. `topic/provenance` |
| `risk/` | risk level or concern, e.g. `risk/security` |
| `source/` | source class, e.g. `source/import` |
| `review/` | workflow aid, e.g. `review/human-required` |

## Rules

- Use lowercase kebab-case after the prefix.
- Prefer 2–5 meaningful tags; do not tag every word.
- Do not encode lifecycle or note type as a tag.
- Introduce a new controlled tag only when it improves retrieval across more than one note.
