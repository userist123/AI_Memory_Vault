## Security findings that change the design
1. Dev servers: Vite CVE-2025-31125/32395/58751/58752/62522 and webpack-dev-server CVE-2025-30359/30360,
   CVE-2026-14620 all need an exposed or cross-site-reachable dev server. Metro CVE-2025-11953 binds externally by
   default. => v1 has NO dev server; static builds only.
2. Emulator guest -> host: 10.0.2.2 maps to the loopback of the machine running the emulator (here: WSL distro),
   where the adb server listens on 5037 unauthenticated. A generated APK with INTERNET permission can reach it.
3. Agent config poisoning: CVE-2025-54135/54136 (Cursor mcp.json), CVE-2025-53773 (Copilot autoApprove),
   CVE-2025-61260 (Codex repo-local config), CVE-2026-30615 (Windsurf). => agents must never write control files.
4. Sandbox confused deputy: CVE-2026-39861, CVE-2026-25725, CVE-2025-59532. => host-side writes must refuse
   links created by sandboxed code; writable root never model-controlled.
5. UI attacks: markdown image exfil (EchoLeak CVE-2025-32711, CamoLeak), ANSI/OSC-52, Unicode tags/bidi,
   spoofed approval text.
6. Supply chain: Shai-Hulud (Nov 2025, >1000 npm versions; reached Maven via mvnpm), Sept 2025 maintainer
   phishing (18 packages), Axios compromise (Mar 2026), Mini Shai-Hulud (May 2026), pub.dev XCSSET (Sep 2026),
   Dart pub zip-slip (fixed Dart 3.11 / Flutter 3.41). Slopsquatting: 19.7% hallucination rate (USENIX Sec 2025).
   Controls: ignore-scripts=true, pnpm minimumReleaseAge (>=10.16), lockfile integrity via npm ci / frozen
   lockfile, npm audit signatures, offline install from pre-populated cache, Gradle verification-metadata.xml.
7. Generated-app defects: Lovable CVE-2025-48757 (missing RLS), leaked keys in client bundles => export gate.
