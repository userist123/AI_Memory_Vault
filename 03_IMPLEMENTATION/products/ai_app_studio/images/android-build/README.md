# aas-android-build (S7, built and probed)

Offline Capacitor 8 debug-APK build (DESIGN 3.5, probes PB7a/PB7b in `tests/build/test_android.py`).

Build (network only here; context = `kit/`):

    docker build -f images/android-build/Dockerfile --build-context aas=images/android-build -t aas-android-build:dev kit
    docker builder prune -f

Image: ~2.0 GB (Temurin 21, platform 36, build-tools 36.0.0, Gradle 8.14.8, studio template, read-only cache).

## Stages
1. `fetch` - `ADD --checksum=sha256:...` for every download (see `../DIGESTS.json`): Temurin 21.0.13.1+2 tarball,
   `platform-36_r02.zip`, `build-tools_r36_linux.zip` (sha1 matched Google's repository2-3.xml), Gradle 8.14.8-bin.
2. `template` - `cap add android` for the kit's lockfile (`@capacitor/android` **8.6.2**: the kit pins 8.6.2, not 8.5.2;
   compileSdk 36 is asserted against `variables.gradle` and the library's `build.gradle`, AGP 8.13.0). Studio overlay
   (`template/`): root and app `build.gradle` (no google-services, no test deps, applicationId from `-PaasAppId` and
   only `dev.aiappstudio.p<16 hex>`, debug signing only with `/keys/aas-debug.keystore`), `gradle.properties`
   (`android.builder.sdkDownload=false`, `aapt2FromMavenOverride` = pinned build-tools, `org.gradle.native=false`),
   wrapper properties with `distributionSha256Sum`, `capacitor.settings.gradle` (plain path instead of the pnpm store).
3. `jdk`/`base` - digest-pinned `python:3.12-slim` + JDK + SDK subset + Gradle + template. Licence: cmdline-tools 23
   refuses `sdkmanager --licenses` ("no longer needed") and its replacement `android` downloads an unpinned CLI, so the
   acceptance is written non-interactively as the sha1 of the licence text; nothing is ever installed while an app
   builds (`sdkDownload=false`).
4. `resolve` - one online `gradle --write-verification-metadata sha256 assembleDebug`: writes
   `gradle/verification-metadata.xml` and fills `modules-2`, copied to `/opt/gradle-ro` (`GRADLE_RO_DEP_CACHE`, lock
   files removed). Fails if any SDK package other than the pinned two appeared.
5. final - non-root (uid 1000), entrypoint `aas-build-android` (`build` | `genkey`).

## Run (core/aas_build/runner.py `build_android_argv`, fixed argv)
`--network none --read-only --tmpfs /tmp:rw,noexec,nosuid,nodev,size=3g --cap-drop ALL --security-opt no-new-privileges
--user 1000:1000 --cpus 4 --memory 4g --pids-limit 1024 --ulimit fsize=512m -e AAS_APP_ID=dev.aiappstudio.p<id16>
-v <current web site>:/dist:ro -v <data>/keys/aas-debug.keystore:/keys/aas-debug.keystore:ro -v <empty out>:/out:rw`.
`/tmp` stays **noexec**: Gradle and the JDK run from `/opt`, aapt2 from the pinned build-tools, native integration off.
Gradle: `--offline --no-daemon --dependency-verification strict`. The script verifies with `apksigner` that the APK has
exactly one signer equal to the mounted studio key and prints `AAS-SIGNER-SHA256=`; the host compares it with
`<data>/keys/aas-debug.cert.sha256` (written when the studio key was generated by `genkey`, never the owner's Android user dir).
Output: only `/out/app-debug.apk` (host reader: one regular file, no link, nlink 1, ZIP magic, <= 100 MB).

Measured 2026-11-23: offline build of the blank kit app ~30 s, APK ~4.1 MB.

## Licence and dependency pinning (S7 review)
- Installing the studio accepts the Android SDK licence on the owner's behalf (owner decision recorded 2026-11-23). The
  Dockerfile writes the acceptance hash into `licenses/android-sdk-license`; that hash could not be verified offline
  (the licence text is only in Google's repository2-3.xml) and is recorded as unverified.
- `template/gradle/verification-metadata.xml` is committed and the build runs `--dependency-verification strict`;
  to change dependencies regenerate it with `gradle --write-verification-metadata sha256`, review the diff, commit.
