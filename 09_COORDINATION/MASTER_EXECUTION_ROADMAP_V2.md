# AI Memory Vault — Master Parallel Execution Roadmap V2

## Mission

Evolve the Vault from a strong governed memory foundation into a demonstrably cognitive memory engine without sacrificing security, provenance, lifecycle semantics or scientific honesty.

## Operating rule

All major work is decomposed into independent parallel lanes:

`CODEX = BUILD`
`ANTIGRAVITY = OBSERVE`
`PERPLEXITY = RESEARCH`
`LUNA = FALSIFY`

No lane waits for unrelated work.

## Phase 0 — Coordination Foundation

Status: COMPLETE

- multi-agent policy exists;
- parallel lane controller exists;
- persistent lane prompts exist;
- R001 launch and barrier template exist;
- evidence namespaces are separated.

## Phase 1 — Retrieval Truth

Goal: establish exactly what retrieval does today.

CODEX:
- runtime retrieval path;
- candidate generation;
- scoring;
- held-out tests.

ANTIGRAVITY:
- end-to-end retrieval trace;
- score decomposition;
- candidate/ranking observability.

PERPLEXITY:
- benchmark methodology;
- lexical/semantic/hybrid design alternatives.

LUNA:
- independent reproduction;
- held-out adversarial cases;
- challenge semantic claims.

Exit criteria:

- retrieval classification supported by code + runtime evidence;
- candidate recall boundary understood;
- ranking behavior measured;
- no benchmark gaming.

## Phase 2 — Trust Boundary Under Retrieved Content

Goal: prove whether retrieved memory remains data or can become authority.

CODEX:
- build end-to-end adversarial tests at memory-to-agent/tool boundary;
- harden only reproduced defects.

ANTIGRAVITY:
- trace trust transitions and action authorization;
- expose memory-to-action flow.

PERPLEXITY:
- research indirect prompt injection, memory poisoning and trust isolation;
- provide testable defenses.

LUNA:
- novel red-team payloads;
- unauthorized-action challenge;
- lifecycle/provenance bypass attempts.

Exit criteria:

- DATA_RETRIEVAL tested;
- AUTHORITY_ESCALATION tested;
- UNAUTHORIZED_ACTION tested;
- REVIEW safety preserved.

## Phase 3 — Associative Cognition

Goal: demonstrate whether graph and activation mechanisms actually improve retrieval.

CODEX:
- controlled A/B harness;
- fixed-candidate experiments;
- implement only validated improvements.

ANTIGRAVITY:
- activation/graph trace;
- candidate movement visualization.

PERPLEXITY:
- compare associative memory mechanisms;
- identify appropriate statistical tests.

LUNA:
- independently reproduce A/B results;
- attack for confounds.

Exit criteria:

- mechanism demonstrably changes retrieval;
- improvement measured against baseline;
- no hidden candidate-set advantage.

## Phase 4 — Epistemic Calibration

Goal: make confidence useful rather than decorative.

CODEX:
- implement calibrated scoring/abstention only from proven requirements.

ANTIGRAVITY:
- reliability visualization;
- threshold/score observability.

PERPLEXITY:
- ECE/Brier/selective prediction research;
- calibration strategy.

LUNA:
- independent calibration challenge;
- detect overloaded confidence values.

Exit criteria:

- relevance confidence separated from source authority;
- correctness confidence not conflated with retrieval score;
- abstention behavior empirically characterized.

## Phase 5 — Temporal and Contradiction Intelligence

Goal: distinguish historical truth from current applicability.

CODEX:
- validate/fix temporal and supersession behavior;
- preserve lineage.

ANTIGRAVITY:
- temporal reasoning traces;
- contradiction visualization.

PERPLEXITY:
- temporal knowledge research;
- provenance/validity models.

LUNA:
- historical/current/future/superseded challenge suite.

Exit criteria:

- historical correctness separated from current validity;
- supersession behavior measured;
- contradiction handling explicit.

## Phase 6 — Closed Learning Loop

Goal:

`OUTCOME → EVIDENCE → MEMORY → RETRIEVAL → FUTURE OUTCOME`

must become demonstrable rather than merely documented.

CODEX:
- trace actual downstream outcome consumption;
- implement human-gated learning path if required.

ANTIGRAVITY:
- memory-use/outcome observability;
- before/after trace.

PERPLEXITY:
- research safe feedback/consolidation patterns;
- reward-hacking defenses.

LUNA:
- independently demand before/after evidence;
- reject telemetry-only loop claims.

Exit criteria:

- evidence is consumed by a future memory state;
- future retrieval can reflect that state;
- promotion remains gated;
- learning effect can be measured.

## Phase 7 — Causal Memory Effectiveness

Goal: determine whether memory causes better outcomes.

Required states:

`MEMORY PRESENT`
→ `MEMORY RETRIEVED`
→ `MEMORY ENTERED FINAL CONTEXT`
→ `MEMORY USED`
→ `MEMORY CAUSED OUTCOME`

CODEX:
- controlled treatment/control harness.

ANTIGRAVITY:
- causal observability and trace completeness.

PERPLEXITY:
- experimental design and statistical validity research.

LUNA:
- independent causal audit;
- confound challenge.

Exit criteria:

- memory effect survives controls for leakage and warm-up;
- oracle is explicit;
- repeated-task contamination is addressed;
- causal claim is no stronger than evidence.

## Phase 8 — Consolidation and Governance

Only after Phases 1-7 produce evidence:

- update canonical architecture;
- promote proven knowledge;
- retire contradicted claims;
- update benchmarks;
- preserve historical evidence;
- update agent prompts and next-round assignments.

No architecture is declared complete merely because all implementation tasks are marked done.

## Round progression

Each round follows:

`OPEN`
→ `PARALLEL_WORK`
→ `EVIDENCE_READY`
→ `BARRIER`
→ `RECONCILIATION`
→ `APPROVED / REWORK / REJECTED`
→ `INTEGRATION`
→ `CI_VERIFIED`
→ `CLOSED`

Then the next round starts from the actual resulting `main` SHA.
