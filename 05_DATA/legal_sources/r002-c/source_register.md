## Exact capture

The branch contains `.github/workflows/r002-c-source-capture.yml`. It captures the official printable pages byte-for-byte, preserves them as `source.html`, derives `source.txt` without changing the HTML source, and writes SHA-256 hashes to `HASHES.sha256` plus this register.

## Version boundary warning

OUG nr. 155/2024 has later amendments outside the two-source scope, including a 2026 amendment visible in the current Portal Legislativ record. R002-C does **not** ingest those later acts as primary sources. Any current-law interpretation beyond the two requested source versions is therefore `LEGAL_REVIEW_REQUIRED` / `NOT_YET_DETERMINED` until an owner-authorized source extension exists.
